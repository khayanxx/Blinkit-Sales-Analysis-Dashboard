# Blinkit-Sales-Analysis-Dashboard

## Project Overview

Developed an interactive Power BI dashboard to analyze Blinkit's sales performance, product categories, outlet types, and customer ratings.

## Tools Used

- Power BI
- Excel
- DAX
- Data Cleaning & Transformation

## Business Questions Answered

- What is the total sales generated?
- Which product categories contribute the most sales?
- How do different outlet types perform?
- How has outlet establishment changed over time?
- What is the average rating across products?

## Key Metrics

- **Total Sales:** $776.32K
- **Number of Items:** 5,517
- **Average Sales:** 141
- **Average Rating:** 3.9

## Dashboard Features

- Sales Overview KPIs
- Fat Content Analysis
- Item Type Performance
- Outlet Establishment Trends
- Outlet Type Comparison
- Interactive Filters

## Key Insights

1. Supermarket Type 1 generated the highest sales.
2. Fruits and Snacks contributed the highest number of items sold.
3. Average product rating remained close to 4.
4. Outlet establishments peaked around 2018.
